# Story forms

Choose based on material, not a permanent formula.

| Form | Beat movement | Useful for | Common failure |
|---|---|---|---|
| Scene and consequence | Action → friction → choice → consequence | A real experience or labeled fiction | Inventing a life lesson before an event |
| Demonstration | Visible puzzle → attempt → result → explanation | Tools, science, motion design | Narrating what the image already proves |
| Investigation | Specific question → evidence → complication → narrower answer | Essays and documentary | Hiding weak evidence behind suspense |
| Dry comedy | Ordinary rule → literal extension → absurd cost → short landing | Relatable habits | Explaining the joke afterward |
| Reversal | Plausible belief → concrete exception → changed rule | Opinion and teaching | Fake contrarianism |
| Quiet observation | Small detail → implication → another detail → recognition | Intimate, reflective material | Generic inspirational language |

For a 30-second story, try one turn. For a longer essay, organize turns by questions the previous evidence makes necessary. Do not impose a hook every three seconds or a universal beat ratio. A useful pause can carry tension.

Switch topic during calibration. A person liking one comedic script does not prove they want every tutorial to become comedy.
