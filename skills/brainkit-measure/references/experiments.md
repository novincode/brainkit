# Experiment design

| Question | Primary evidence | Important confounds |
|---|---|---|
| Did packaging earn a start? | Platform-appropriate impressions/start metrics | Traffic source, recommendation exposure, topic |
| Did viewers continue? | Retention by time and completion in context | Duration, audience fit, autoplay, rewatches |
| Did viewers value it? | Relevant actions and qualitative responses | Prompting, incentives, selection bias |
| Does the voice fit? | Blind paired listening and reasons | Loudness, playback device, order, familiarity |
| Did the skill help? | Same-brief baseline vs skill, blind rating | Model, prompt, sampling, judge preference |

Predeclare primary outcome, baseline, meaningful improvement threshold, allowed cost, sample/stopping rule, and exclusion criteria. Select sample size based on the effect and uncertainty required; do not use a universal viral-content threshold.

Record raw counts and definitions alongside derived rates. A 100% completion on a tiny or atypical sample is weak evidence. If no randomized assignment exists, describe association and a plausible next experiment.

Reference for interpreting retention: https://support.google.com/youtube/answer/9314415. A spike is not automatically praise; it may be replaying, sharing, or confusion.
