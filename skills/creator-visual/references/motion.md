# Motion as explanation

For each move state its job: reveal, compare, connect, redirect attention, establish space, or express a character. If the job is only “make it more engaging,” inspect whether it distracts from the story.

Keep meaningful states readable. Anticipation can prepare an action; a held frame can create tension; continuity can show that two views represent the same object. Match easing to the event rather than applying one curve everywhere.

Build the main poses and transitions before secondary effects. Preview motion in context with speech. Remove movement that masks a reveal, competes with the focal point, or forces the viewer to read and listen to different claims simultaneously.

Storyboard rows: shot ID, viewer question, spoken line, on-screen action, text, approximate start/end, transition reason, asset provenance, and render checks. Times are estimates until audio/animation exists. Avoid over-specifying dozens of keyframes before the pacing is tested.
