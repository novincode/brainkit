# Video generation

Start with a shot's narrative job, not a long list of camera buzzwords. Define initial state, subject/action, camera behavior, environment, final state, duration, aspect ratio, continuity constraints, and reference assets. Keep complex multi-event sequences in separate shots when the tool cannot reliably maintain them.

Use image-to-video when preserving a chosen design matters. Keep continuity notes for character, clothing, proportions, light direction, geography, and object state. Mark elements that may change and those that must not.

Before generation, inspect actual provider capabilities, duration limits, audio support, frame controls, cost, and output terms. Never invent support for a named parameter. Generate a short pilot before committing a long sequence when cost or coherence is uncertain.

Review the whole clip, not just the first frame: warping, object persistence, unwanted cuts, action completion, camera logic, artifacts, and spoken/audio alignment. Extract stills only for bounded visual checks; continuous playback is necessary for temporal quality. A prompt-only plan is not a produced video.
