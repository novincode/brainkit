# Production coverage

BrainKit directs a production through portable instructions. Actual media generation, browsing, rendering, and listening depend on the host's connected tools. No bundled API runner or automatic integration is claimed.

| Stage | Owner | Concrete output | Evidence before calling it complete |
|---|---|---|---|
| Audience and premise | Director | Brief and supported promise | Assumptions stated; facts supplied |
| Source research | Research | Source-linked study | Inspected modalities and limits recorded |
| Story and script | Story | Spoken words and beat progression | Read-aloud edit; payoff matches opening |
| Taste consistency | Review | Scoped accepted preferences | Actual feedback rather than guessed personality |
| Art direction | Visual | Layout, type, palette, storyboard | Small-size and story coherence review |
| Image generation/editing | Media | Prompt/reference brief and selected image | Inspect actual output and required fidelity |
| Voiceover | Voice | Clean/tagged text and audition record | Actual listening, pronunciation, measured duration |
| Video generation | Media | Shot briefs, pilots, continuity record | Whole-clip inspection |
| Motion design | Visual + Media | Poses, transitions, rendered sequence | Playback with voice |
| Music | Media | Music brief, cue sheet, selected bed | Listen with actual dialogue and check rights |
| Sound effects and mix | Media | Sync cues, stems, mix | Intelligibility and playback checks |
| Editing and captions | Media | Rough cut, final cut, captions | Review speech/text timing and narrative continuity |
| Packaging | Director + Visual | Honest title, thumbnail, description | Promise matches finished content |
| Export and delivery | Media | Tested exports and asset manifest | Open the actual exported files |
| Publication and learning | Measure | Experiment record and findings | Authorized publication and real analytics |

## Optional tools

Use the host's available image generator, TTS provider, video generator, music/sound generator, editor, and renderer. Ask for a missing tool only if it blocks the requested artifact. A disconnected provider should produce a usable brief/handoff, not invented media or fake completion.

AtomCut/Remotion and provider-specific integrations remain optional. Read their current skill/API documentation when executing; provider parameters do not belong in the storytelling core. Generation and publication authorization remain separate.

## Current release limits

The foundation includes procedures and test cases. Live cross-provider production benchmarks, model-specific media adapters, and automated end-to-end generation are not implemented. The repository should earn additional integrations through actual productions and recorded failures.
