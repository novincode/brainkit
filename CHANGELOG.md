# Changelog

## 0.3.0 — 2026-10-19

- Standardize all nine skill names, package directories, prompts, registry entries, and examples under the `brainkit-` namespace.
- Rewrite the README around installation, production workflows, and practical use. Keep validation records in development documentation.
- Update publication guidance for the live novincode/brainkit repository.

### Upgrade

Skill names changed in this release. Remove earlier installed package copies after preserving local edits, then reinstall the desired BrainKit packages. Update saved prompts and automation references to match the current registry. The installer does not delete previous packages automatically.

## 0.2.0 — 2026-10-19

- Brand the Codex-built edition as BrainKit with a task-led README and editorial cover.
- Add brainkit-media for image/video generation, music, sound, editing, and inspected delivery; add four behavioral cases.
- Add production scope, launch guidance, funding links for novincode, and contributor templates.
- Provider execution remains host-dependent; publication is tracked separately from preparation.

## 0.1.0 — 2026-10-19

- Establish eight portable skills, directly linked references, project contracts, and progressive loading.
- Add original script calibration set, evidence bank, feedback templates, provider audition plan, and staged roadmap.
- Add non-overwriting installer, structural checks, CI, and meaningful isolation tests.
- Behavioral and performance benchmarks are pending; this release establishes the baseline.
