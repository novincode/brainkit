# Annotation procedure

For each meaningful beat, record source position, observed change, viewer question, supplied evidence, and possible function. Keep speech, on-screen text, footage, music, silence, and edit transitions in separate columns when actually available.

Minimum study:

- Source and inspected modality: transcript, creator-authored text, sampled frames, continuous video, audio, metadata, or combinations.
- Opening promise and eventual payoff.
- Two to five specific decisions that change understanding.
- One alternative explanation for success.
- One failure case where the mechanism would be a bad fit.
- One original transfer task and a measurable or judgeable prediction.

“The transcript moves from a single participant to a group” is observable. “This lowers the viewer's uncertainty” is an interpretation. “Moving the second participant earlier improves completion” is a testable hypothesis. None proves actual viewer psychology.

For distinctive creators, compare repeated choices across at least three inspected works before generalizing. Describe material-level tendencies rather than assigning an unchanging personality.
