# Image production

Write an image brief as a visual decision: purpose, subject/action, composition, medium/material, palette, lighting, aspect ratio, required facts, reference usage, and unwanted failure modes. Avoid stacking empty adjectives such as cinematic/premium/stunning without explaining what the viewer should see.

Explore three mechanisms rather than three color swaps. For example: an image that demonstrates a comparison, one built around a physical metaphor, and one showing a specific event. Explain why each fits the story.

For identity consistency, keep a reference sheet, palette, proportions, and immutable details. Prefer editing a selected direction over repeatedly generating unrelated images. Do not assume text prompts alone preserve identity. Preserve actual architecture or product geometry when the brief requires factual fidelity.

Inspect the output: anatomy/geometry, required text, composition, negative space, small-size readability, factual details, continuity, and unwanted style artifacts. A successful generation response does not establish a good image. Keep the prompt, model/date, references, version, and selected output together. Never put private reference images in a public repo without sharing authorization.
