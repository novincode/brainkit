# Handoffs

Use an artifact handoff instead of passing the entire conversation.

| Field | Carry forward |
|---|---|
| Project and artifact version | Stable ID; never overwrite evidence with guesses |
| Viewer and promise | One sentence each |
| Facts | Supported claims plus source IDs; unknowns separate |
| Taste | Only relevant accepted preferences |
| Current artifact | Script, storyboard, study, or audition plan |
| Next task | Specific deliverable and constraints |
| Open decision | At most one blocking creative question |

For a short: brief → script → read-aloud revision → voice/shot plan → preview → review. Skip stages the user did not request. For a research question, stop at evidence and a proposed transfer test.

Check consistency: thumbnail raises the same question the opening answers; voice emphasis lands on the same turn the visual reveals; on-screen text adds information or accessibility rather than competing with speech. If a story changes, invalidate downstream timing estimates explicitly.
